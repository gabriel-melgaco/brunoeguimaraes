# Bruno & Guimarães — Site Oficial

Site institucional da dupla sertaneja **Bruno & Guimarães**, de Taubaté - SP.

🌐 **Acesse:** [brunoeguimaraes.megdev.com.br](https://brunoeguimaraes.megdev.com.br)

---

## Sobre o Projeto

Landing page desenvolvida para divulgação da dupla sertaneja Bruno & Guimarães, contendo:

- **Hero com vídeo** em tela cheia com controle de áudio
- **Sobre a Dupla** — história e estatísticas
- **Carrossel de Shows** com suporte a swipe mobile
- **Contato** via WhatsApp e Instagram
- **Botão flutuante** do WhatsApp

## Tecnologias

- HTML5
- CSS3 (responsivo, sem frameworks)
- JavaScript Vanilla
- GitHub Pages (hospedagem)
- Domínio customizado via CNAME
